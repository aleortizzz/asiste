# invitaciones-demo

Carpeta temporal para tirar imágenes de prueba mientras se le da forma al diseño
de las invitaciones.

- Todo lo que pongas acá se sirve en `http://localhost:5173/invitaciones-demo/<archivo>`
  y se referencia desde el código como `/invitaciones-demo/<archivo>`.
- Las imágenes de esta carpeta están ignoradas por git (ver `.gitignore` raíz),
  así que no se commitean. Solo se versionan este README y el `.gitkeep`.

## Pendiente

Cuando la gente pueda subir sus propias imágenes, hay que moverlas a un storage
real (Supabase Storage es lo más directo dado que ya usamos Supabase). Esta
carpeta es solo para desarrollo.
